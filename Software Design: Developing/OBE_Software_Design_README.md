# OBE-Based Software Design Question Paper

**Total Marks:** 40  
**Duration:** 1 Hour

**Instructions:** Answer all questions. Each question carries 5 marks.

---

## Q1. Software Design Fundamentals [5 Marks]

a) Define software design. [2]

b) Explain the difference between architectural design and detailed design. [3]

## Q2. Principles of Good Design [5 Marks]

a) Define coupling and cohesion. [2]

b) Explain why low coupling and high cohesion are desirable in software design. [3]

## Q3. Software Architecture [5 Marks]

a) What is software architecture? [2]

b) Describe the roles of Model, View, and Controller in MVC architecture. [3]

## Q4. Design Quality Metrics [5 Marks]

a) What are software design metrics? [2]

b) Explain the purpose of any three metrics: CBO, LCOM, WMC, RFC, DIT, and NOC. [3]

## Q5. Object-Oriented Design Patterns [5 Marks]

a) What is a design pattern? [2]

b) Name the three main GoF design pattern categories and give one example of each. [3]

## Q6. Selected Design Patterns [5 Marks]

a) State the intent of the Strategy pattern. [2]

b) Explain how the Adapter pattern helps incompatible classes work together. [3]

## Q7. Enterprise Application Patterns [5 Marks]

a) What is Object-Relational Mapping (ORM)? [2]

b) Explain the role of Data Mapper (Repository/DAO). [3]

## Q8. User Interface Design [5 Marks]

a) State any three fundamental UI design principles. [3]

b) Explain any two UI interaction modalities. [2]
